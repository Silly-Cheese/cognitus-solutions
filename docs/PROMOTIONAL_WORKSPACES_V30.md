# Promotional Access V30 — Feature Workspaces

V30 redesigns the actual promotional feature pages rather than only the Promotional Access hub.

The existing feature logic remains intact. V30 adds a presentation and interaction layer that gives each tool a distinct workspace identity while preserving existing Cognitus data-access rules, redemption logic, mobile support, and feature entitlements.

## Workspace treatments

- Intelligence Center: dark intelligence desk, subject dossier, metrics, and evidence columns.
- Relationship Mapping: dark graph canvas, graph legend, subject core, and connected-node treatment.
- Deep History: editorial historical stream with stronger timeline hierarchy.
- Advanced Search: dedicated discovery/filter console and structured results surface.
- Cognitus Comparison: split analysis board with automatically emphasized differences.
- Network Explorer: dark organization-network result surface.
- Watchlist: private watch desk with a persistent composer and saved-subject vault.
- Saved Investigations: case-workspace composer and investigation vault.
- Intelligence Reports: report studio with sticky actions and a paper-style report document.
- Account Change Comparison: snapshot-vault workspace.
- Cognitus Labs: dedicated experimental deck with dark lab cards.
- Enhanced Profile Cards: profile design studio and premium profile preview.
- Search Collections: research-library composer and saved collection vault.
- Search Analytics: usage cockpit with metrics and activity analysis.
- Priority / Early Access: release-channel timeline board.

## Shared workspace system

Every promotional feature receives a compact Cognitus command strip, a feature-specific tool-stage header, improved empty states, clearer result staging, and stronger card hierarchy. Responsive rules keep these workspaces usable on the V29 mobile/tablet experience.

V30 does not change Firestore security rules or the underlying feature-entitlement model.
